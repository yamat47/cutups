## 何か

プレーサイドのエンドを1人ブロックせずに残し、QBがその内側へ縦に走り込んでから、外を回るRBへピッチするかを決めるオプション。ラインの別の動き(OLのフォルス・プルなど)で2列目を逆へ寄せ、その場に止めておくことから名前が付いていると読める。エンドがQBに来ればピッチ、外のRBに付けばQBがそのまま走る。

## 見分け方

スナップ後、プレーサイドのエンドの前に誰もブロックに行かない。QBはボールを持ったまま、そのエンドの内側へ短く前へ出る。RBはQBの外側、ピッチを受けられる間隔を保ってサイドライン方向へ回る。図ではブロックしないエンドが灰色の円で囲まれ、QBからRBへ点線が引かれる。
